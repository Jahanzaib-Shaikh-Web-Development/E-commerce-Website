# ShopSphere React E-commerce

A responsive React + Vite storefront prototype with a premium navy/blue visual identity.

## Run locally
1. Install Node.js 18+.
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open the local URL Vite prints.

## Build for production
`npm run build`

## Features
- Responsive layouts for desktop, tablet, and mobile
- Search, category filtering, price range, and sorting
- Product details with quantity selector
- Add/remove cart items and change quantities
- Wishlist toggles
- Cart totals, free-shipping threshold, and demo checkout
- Login/register demo forms and contact form
- Newsletter form feedback
- Cart and wishlist saved in localStorage
- Accessible button labels and keyboard-accessible product cards

## Demo limitations
This is a front-end demo. Checkout does not collect payment or submit a real order. Login/register and contact/newsletter forms do not connect to a backend. Product imagery is loaded from Unsplash and requires internet access. For production, add a secure backend, authentication, inventory, order APIs, and a payment provider.
